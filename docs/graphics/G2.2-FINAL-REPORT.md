## 1. Executive Summary

Milestone G2.2 advances the authentic upstream SDL 3.2.0 integration into a hardened, reproducible, architecture-compliant state while reconciling evidence across engineering tracks.

### Key Accomplishments
1. **Separation of Qualification Targets**: Established two distinct, unambiguous targets:
   - **Target A (Hardened Baseline `sdl3_app`)**: Freestanding, strictly avoids SSE instructions, and passes live QEMU guest qualification inside the ArenaOS desktop with clean process exit 0.
   - **Target B (Genuine Upstream SDL 3.2.0 `sdl3_upstream_demo`)**: Built from the authentic upstream SDL 3.2.0 source tree (81 compiled C modules). Statically passes all kernel ELF loader rules ($100 \le 128$ load pages, $243,512 \le 262,144$ bytes). Guest execution is honestly documented and classified as **BLOCKED on CPU State (Blocker B1 / B-FP-2)** without synthetic workarounds or false claims.
2. **Reconciliation of Memory & ELF Reports**: Resolved the prior measurement discrepancy between 98 pages and 100 pages, delivered a deterministic kernel ELF auditor (`tools/audit_elf.py`), and confirmed that all final receipts agree on the exact same build.
3. **Elimination of Allocator Scaffolding Defects**: Refactored `arenaos_memory.c` with 32-byte headers guaranteeing strict 16-byte user pointer alignment across all allocations, verified pointer ownership via magic tags (`ARENAMEM`), added double-free detection, and verified safety with an 8-test unit suite.
4. **Canonical ARST v2 Startup Gate**: Replaced partial startup checks with Arena 2's canonical ARST v2 parser, unmapping and destroying Slot 0 immediately after copying, and executing an exhaustive 128-slot live capability inventory check via `SYS_CAP_DESCRIBE`. Verified with an 8-test negative test suite.
5. **Timer & Event Protocol Hardening**: Corrected the timer syscall contract in `arenaos_client.c`, passing `timer_id` instead of capability slots to `SYS_TIMER_CANCEL`, eliminating redundant cancellations on expired timers, and implementing full-window fallbacks for damage rectangles exceeding ADSK-v1 bounds.
6. **Disassembly-Based CPU Architecture Auditing**: Delivered `tools/isa_audit.py` with positive/negative self-tests. Disassembled and categorized all 33,886 instructions across 663 functions, documenting the exact AMD64 System V ABI float dependencies for Luna in `docs/graphics/G2.2-CPU-DEPENDENCIES.md`.
7. **Arena 2 C2 Integration Handoff**: Audited Arena 2's C2 release (`arena/f89ea987-arenaos`), identified components ready for reuse, and authored `docs/graphics/G2.2-C2-INTEGRATION.md` detailing the resolution of Blocker B-GFX-1.

## 4. Allocator Hardening Receipts (G2.2.2)

The freestanding allocator in `arenaos_memory.c` was redesigned:
1. **16-Byte Pointer Alignment Guarantee**:
   $$\text{sizeof}(\text{BlockHeader}) = 32\text{ bytes } (\text{multiple of } 16)$$
   Every returned user pointer $(header + 32)$ is strictly 16-byte aligned.
2. **Ownership Validation**:
   - Every block header stores `ARENA_MEM_MAGIC` (`0x4152454E414D454DULL`).
   - Pointers passed to `free()` and `realloc()` are bounds-checked against `s_heap`, alignment-checked, and magic-verified before dereference.
   - Double-free calls are detected (`hdr->is_free == 1`), incrementing `s_bad_frees` and returning safely without corrupting the free list.
3. **Safe Realloc & Calloc**:
   - `calloc` checks for multiplication overflow (`nmemb * size`).
   - `realloc` preserves existing allocations if expansion fails and refuses unvalidated foreign pointers.

## 5. Startup Gate Validation Receipts (G2.2.3)

`arenaos_entry.c` implements canonical ADR-0083 / ADR-0086 startup ingestion:
1. Ingests Slot 0 SharedRegion (`RIGHT_READ | RIGHT_DESTROY`, 1 page).
2. Maps read-only, copies 4096 bytes into private static BSS, unmaps, and destroys Slot 0.
3. Parses canonical ARST v2 layout: magic `ARST`, version 2, header length 128, valid alphanumeric app ID, contiguous section offsets, and padding checks.
4. Performs live 128-slot capability inventory audit using `SYS_CAP_DESCRIBE`:
   - Slots 1 through `capc` must be occupied with matching kind and rights.
   - Slots `capc + 1` through 127 must be unoccupied.
   - Any unexpected grant fails closed with exit code **122**.
5. Verifies graphical profile:
   - Slot 1: Desktop BadgedEndpoint (kind 12, `RIGHT_WRITE`)
   - Slot 2: Window Surface SharedRegion (kind 7, `RIGHT_READ | RIGHT_WRITE`)
   - Slot 3: Notification (kind 3, `RIGHT_WRITE`)

## 8. Architectural Blockers & Track Handoff

| Blocker ID | Description | Responsible Track | Resolution / Handoff Specification |
|---|---|---|---|
| **B-FP-2 / B1** | Kernel `#UD` on ring-3 SSE instructions (`CR4.OSFXSR` not enabled; context switch does not save FPU/SIMD state) | **Luna** (Phase 14 / CPU State) | Enable `CR4.OSFXSR` in `kernel/boot/src/m1.rs`; implement thread FPU save area (512 B) and `fxsave64`/`fxrstor64` in `kernel/kernel/src/arch/x86_64/context.rs`. Specification delivered in `docs/graphics/G2.2-CPU-DEPENDENCIES.md`. |
| **B-GFX-1** | No service identity in ARST v2 for graphical descriptors (all carry role `Other`) | **System Architecture / Arena 2** | Propose Option A (new ARST roles `ROLE_GRAPHICS_ENDPOINT = 9`, `ROLE_GRAPHICS_SURFACE = 10`, `ROLE_GRAPHICS_NOTIFY = 11`) or Option B (runtime IPC connect handshake). Documented in `docs/graphics/G2.2-C2-INTEGRATION.md`. |
| **B-FP-1** | No soft-float runtime (`-msoft-float` emits `libgcc` calls which `-nostdlib` excludes) | **Arena 2** (C2 Runtime) | Required before compiling float-using C code with general-regs-only toolchains. |
| **ADSK-v1 Key Up** | Desktop protocol delivers atomic `Event::Key(code)` without key release flags | **Desktop Compositor** | Documented protocol boundary; SDL backend translates atomic key events into immediate down/up pairs. |
