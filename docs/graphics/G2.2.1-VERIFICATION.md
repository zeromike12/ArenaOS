To execute the entire host qualification and regression test suite:


## 2. Gate 1: Host C Unit Tests (Tasks 2, 3, 6)

### Command:
```bash
bash experimental/upstream-sdl3/tests/run_tests.sh
```

### Verification Criteria:
- **Allocator Safety & Concurrency (`test_allocator`):**
  - Verifies 16-byte alignment across all allocation sizes.
  - Verifies realloc payload preservation and in-place expansion/shrinkage.
  - Safely refuses foreign, unaligned, or double-freed pointers.
  - Verifies calloc integer overflow checks and zero initialization.
  - Gracefully returns `NULL` on 128 KiB heap exhaustion without corrupting heap metadata.
  - Verifies coalescing and memory block reusability.
  - Verifies thread safety under 4 concurrent pthreads (400 alloc/realloc/free cycles).
  - Verdict: `ALL 9 ALLOCATOR SAFETY & CONCURRENCY TESTS PASSED!`
- **Canonical ARST v2 Startup Gate (`test_startup`):**
  - Links directly to production parser `arenaos_entry.c`.
  - Tests canonical valid ARST v2 page, bad magic, unsupported version, undefined flags, malformed app ID, non-zero padding, non-consecutive capability slots, tampered offsets, string table out-of-bounds, integer arithmetic overflow, overlapping descriptors, embedded NUL byte, empty argv[0], empty env, oversized storage capacity refusal, incomplete string table coverage, and duplicate unique capability roles.
  - Verdict: `ALL 18 CANONICAL STARTUP VALIDATION TESTS PASSED!`
- **Timer and Notification Rights Contract (`test_timer_contract`):**
  - Verifies `SYS_TIMER_ARM` requires WRITE rights on notification.
  - Verifies `SYS_WAIT` requires READ rights on notification.
  - Verifies `SYS_WAIT` on WRITE-only notification (Desktop Slot 3) is rejected with `STATUS_BAD_ARG`.
  - Verifies `SYS_TIMER_CANCEL` takes `timer_id`, not capability slot index.
  - Verdict: `ALL 5 TIMER CONTRACT TESTS PASSED!`
