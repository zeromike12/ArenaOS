# Milestone G2.2.2 & G2.3 Verification and Reproduction Guide

This guide details the exact sequence of commands to verify all deliverables for Milestones G2.2.2 (Final Graphics Qualification) and G2.3 (Genuine Upstream SDL 3.2.0 + Shared C Runtime Integration).

---

## 1. Quick Verification Command Summary

Run the complete qualification test sweep:

```bash
# 1. Whole-executable ISA Auditor Self-Test (6 controls)
python3 tools/isa_audit.py --self-test

# 2. Host Unit Test Suites (Allocator, Startup Gate, Timer Contract, IEEE-754 Safe Bitwise)
bash experimental/upstream-sdl3/tests/run_tests.sh

# 3. Target A Baseline Guest Harness Mock Suite (14 unit tests including 6 negative controls)
python3 tools/test_sdl3_guest_mock.py

# 4. Target A Static Audit & Loader Verification
python3 tools/test_sdl3_guest.py --mode audit

# 5. Target A Guest Execution Gate (Fails closed with exit code 2 when QEMU is absent)
python3 tools/test_sdl3_guest.py --mode guest; echo "Guest exit code: $?"

# 6. Build Genuine Upstream SDL 3.2.0 with Shared C Runtime (C2) Target
bash experimental/upstream-sdl3/build_upstream_c2.sh

# 7. Dedicated Upstream Guest Harness Mock Suite (7 unit tests)
python3 tools/test_upstream_sdl3_guest_mock.py

# 8. Dedicated Upstream Static Audit (Verifies C2 and Standalone ELF loader budgets)
python3 tools/test_upstream_sdl3_guest.py --mode audit

# 9. Dedicated Upstream Guest Execution Gate (Fails closed with exit code 2: BLOCKED on CPU state)
python3 tools/test_upstream_sdl3_guest.py --mode guest; echo "Upstream guest exit code: $?"
```
