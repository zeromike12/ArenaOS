## 3. Three-Stage Sequential Integration Sequence

### Stage 1: Integrate Luna Phase 15 into Mainline
- **Objective:** Land per-thread FP/SIMD state saving in the ArenaOS microkernel to eliminate Blocker B1 / B-FP-2.
- **Kernel Modifications Required:**
  1. **CPU Bootstrap (`kernel/src/arch/x86_64/cpu.rs`):**
     Set `CR4.OSFXSR` (bit 9) and `CR4.OSXMMEXCPT` (bit 10) during CPU initialization. Enable `CR4.OSXSAVE` if AVX feature flags are supported.
  2. **Thread Control Block (`kernel/src/task/thread.rs`):**
     Add a 512-byte 16-byte aligned buffer (`fxsave_area: [u8; 512]`) to each thread structure.
  3. **Context Switch Assembly (`kernel/src/arch/x86_64/switch.S`):**
     Execute `fxsave (%rdi)` for the outgoing thread and `fxrstor (%rsi)` for the incoming thread across thread scheduling switches.
- **Verification Gate:**
  Execute `python3 tools/isa_audit.py --self-test` in kernel space; verify user-space SSE instructions no longer trigger vector `0x06` (`#UD`).

### Stage 2: Unify Arena 2 C2.1 Shared C Runtime
- **Objective:** Establish `experiments/c-runtime` as the primary standard C runtime for all ArenaOS C applications.
- **Integration Steps:**
  1. Promote `experiments/c-runtime` to `userspace/c-runtime`.
  2. Build `libarena_c.a` and `crt0.o` with static PIE compliance (`-fno-pie -no-pie` or `-fpie` as dictated by Phase 14 loader).
  3. Validate canonical ARST v2 startup record parser against all 18 host test controls (`test_canonical_startup.c`).
- **Verification Gate:**
  Host unit tests in `experimental/upstream-sdl3/tests/run_tests.sh` pass with 0 warnings.

### Stage 3: Land Milestone G2.3.1 Graphics Stack & Unblock Guest Execution
- **Objective:** Link genuine upstream SDL 3.2.0 against the unified C runtime and execute the 24-step guest qualification under the Phase 15 kernel.
- **Integration Steps:**
  1. Rebuild `libSDL3_upstream_c2.a` and `sdl3_upstream_c2` using `build_upstream_c2.sh`.
  2. Run `tools/test_upstream_sdl3_guest.py --mode guest --target c2`.
  3. In Step 6/24 of the harness, `inspect_kernel_simd_capability()` inspects the integrated Phase 15 kernel and reports:
     `QUALIFIED: Phase 15 per-thread FP/SIMD context preservation detected`.
  4. The harness automatically executes through all 24 guest lifecycle steps:
     Desktop enumeration -> APB1 install -> AFS2 verification -> application launch -> surface presentation -> frame milestones 0/25/59 -> clean exit 0 -> UEFI shutdown.
- **Verification Gate:**
  `tools/test_upstream_sdl3_guest.py --mode guest` exits with status `0` (`PASS`).

## 4. ABI Stability & Capability Wire Invariants

The integrated graphics stack maintains strict backward compatibility with existing ArenaOS system contracts:

1. **Broker Slot Authority (V2 Contract):**
   - Slot 0: Null
   - Slot 1: Service Endpoint (`CALL`)
   - Slot 2: Surface SharedMemory (`READ | WRITE`)
   - Slot 3: Hardware Timer Notification (`READ | WRITE`)
2. **Syscall Numbering:**
   - `SYS_TIMER_ARM = 27` (positive 32-bit `timer_id` returned)
   - `SYS_TIMER_CANCEL = 28` (accepts `timer_id`, NOT capability slot index)
   - `SYS_WAIT = 11` (blocks caller until badge delivery; zero busy spinning)
   - `SYS_VM_RESERVE = 32`, `SYS_VM_COMMIT = 33`
3. **Wire Protocol (ADSK-v1):**
   - Fixed 64-byte message frame format (`magic = "ADSK"`, `version = 1`).
   - Opcodes: `Create (1)`, `Damage (2)`, `Poll (3)`, `Title (4)`, `Event (5)`, `DestroyWindow (11)`.
   - Maximum 5 damage rectangles per frame; automatic fallback to `adsk_damage_full()` on overflow.

## 5. Risk Analysis & Failure Mitigation

| Risk Description | Severity | Likelihood | Mitigation Strategy |
|---|---|---|---|
| **Unaligned FXSAVE Buffer** | High | Low | Enforce `align(16)` on thread struct FP state buffer; add runtime kernel assertion `(va & 0xF) == 0`. |
| **Kernel Stack Pressure** | Medium | Low | Ensure scheduler switch frames allocate stack space outside the 512-byte FXSAVE buffer. |
| **Image Load Budget Overflow** | Medium | Medium | Maintain `-DHAVE_LIBC=1` and `-Wl,--gc-sections` across SDL3 build; keeps static PT_LOAD footprint at 50 pages (ceiling is 128). |
| **Capability Rights Regression** | High | Low | Automated regression test `test_timer_contract.c` asserts `RIGHTS_WRITE` is required for timer arming and `RIGHTS_READ` for waiting. |
