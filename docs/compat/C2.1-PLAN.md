| D1 | `src/libc_threads.c` `mtx_init` | Checks only `mtx_recursive`. `mtx_timed` and unknown bits are accepted silently, and `mtx_timedlock` is then refused, so the type lies about its capability. | C2.1.1 | Accept only `mtx_plain` (exact value 0). a valid termination witness; the mutex does not record its owner (a documented limit, unchanged).

## 3. Scope decisions

- **No kernel or ABI change.** The kernel synchronization ABI (`SYS_SYNC_*`, `SYS_THREAD_*`) is
  used exactly as C2 uses it. No syscall, capability type, or ARST field is added. `arena_startup_t`
  is not changed; "ambiguous" is represented by `notification == ARENA_ARST_NONE` plus
  `ARENA_E_NO_WAITER`, not by a new field or status code.
- **No new symbols** to inflate coverage. The only new code paths are corrections of existing
  functions and refusals.
- **Mutex type policy.** Only `mtx_plain` is supported. `mtx_timed` is refused at init, not
  accepted and then refused later, so a caller learns the capability at the correct point.
- **Timed waits.** Refusal over clamping: a deadline that needs more than the kernel's
  86,400 s bound is refused. A clamp would turn a long wait into an early `thrd_timedout`, which
  is a false answer.
- **`setvbuf`.** Only unbuffered is implemented. The historical App A assertion
  `setvbuf(stdout, NULL, _IOLBF, 0) == 0` asserted acceptance of a mode the runtime does not
  implement, so it is replaced with a refusal assertion. That is a correction, not a weakening: the
  replacement fails if the runtime ever accepts a mode it does not implement.
- **Guest check total.** The task requires an exact total. The C2 total was 66. C2.1 adds checks
  for detached-thread termination, `thrd_exit`, `getchar`, `clock` and `time`, and the notification
  and ordering checks. The exact new total is set in `guest_c2.py` as a single constant and
  documented in `C2.1-VERIFICATION.md`, with the mapping from the C2 total. No historical check is
  removed without a replacement.
- **ASan/UBSan.** The thread runtime is guest-only (`libc_threads.c` is not built on the host). The
  host can test `atexit` concurrency with pthreads, and the stdio and mutex-type policy through
  host-compiled code where the code is host-compiled. Guest-only properties are labelled GUEST.
- **FP.** No floating-point formatting is added. Refusal is unchanged.

## 5. Evidence rules

- Every number in the final report cites the commit it was produced from.
- A guest verdict is accepted only when the exact verdict rules pass. A `RESULT` line alone does not count.
- No claim of production 100/100 boot qualification. No claim of full libc, POSIX, or SDL3 support.
- Host ASan/UBSan results are not kernel-side memory-safety proof.
- The RFC 8032 development fixture is test-only and is never presented as a production key.
