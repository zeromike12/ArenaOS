## 5. Arena 1 integration steps

Arena 1 (`arena/13f9221b-arenaos`) must stay on its own branch. C2.1 gives it a contract, not a merge.

1. Use the C2.1 runtime at `9c93f8c` or any later commit whose runtime paths are unchanged. Confirm
   with `git diff --stat <evidence>..<commit> -- experiments/c-runtime/src experiments/c-runtime/include experiments/c-runtime/link`.
2. Build the static artifacts with `python3 experiments/c-runtime/run.py --cc gcc build`. The Clang
   build also needs `ARENA_ZIG=<zig binary>`.
3. Compile and link using the command in `C2-SDL3-INTEGRATION.md` §2 verbatim. The order is:
   `crt0.o` first, then application objects, then `libarena_c.a`, with `link/arena-user.ld`, and
   `-nostdlib -static -no-pie -Wl,--no-dynamic-linker`. Do not add `libgcc` or a system libc.
4. Replace duplicated runtime pieces with the C2.1 functions, one group at a time, following
   `C2-SDL3-INTEGRATION.md` §10. Do not keep a second allocator, a second thread layer, or fake pthreads.
5. Do not call `_exit` (it is not defined). Use `exit` or `_Exit`. Do not rely on `atexit` after
   `_Exit`, `abort`, or in a threaded exit race.
6. Do not rely on `tss_get` to detect support. Use `tss_create`, which refuses.
7. Do not use `time`, `clock`, `CLOCK_REALTIME`, `fopen`, or `tss_*` as working features.
8. For notification selection, pass the validated candidate list. Ambiguous candidates return
   no selection. Do not guess.
9. Floating point and SIMD are **not** available. Any upstream library that needs them is blocked
   (section 6).
10. Run your own guest qualification with the C2 suite (`guest_c2.py --cc <gcc|clang>`) before
    claiming any integration. Do not treat these results as Arena 1 results.

Blocked libraries by the no-FP profile: SDL3 (its shipped Linux path links only glibc, and optional
backends are dynamic), Blender (glibc 2.28+, OpenGL or Vulkan, SSE4.2), and SuperTuxKart (SDL2,
OpenAL, and more). None can run in the current profile.

## 7. Clang weak-reference note

Clang app ELFs (C2 console, xxHash, C1 native) carry one **weak undefined** reference,
`arena_legacy_write`. No object in the application defines it, so the legacy debug sink is not
linked, and `rt.c` calls it only behind a NULL check. The GCC app ELFs carry no undefined symbols.
This is an accepted, documented artifact. It is **not** a clean result. The root cause (which
object keeps the reference under Clang) is open (B9).

## 8. What is not claimed

- Not production. No 100/100 claim.
- No production kernel, syscall, capability, ARST, signed-package, or loader change.
- No general floating point, SIMD, or FP state.
- No full libc, POSIX, pthreads, dynamic linker, or upstream SDL3 or Blender compatibility.
- Host ASan and UBSan results are not kernel memory-safety proof.
- The RFC 8032 development fixture is used in tests only and is not a production key.
- ADR-0111 is unresolved. ADR-0110 (Luna's) is untouched. ADR-0112 is Proposed, not accepted.
- M9 is a proposal only.
